"Transferring" a CapCut project usually means one of two different jobs: opening the same project on another device, or moving the edit into a different app. CapCut only supports the first one natively.

This guide covers the official cloud-sync flow, how to find projects that never reached the cloud, and what to do when you want to leave CapCut entirely.

## Same account, automatic sync

When you are signed in, CapCut saves projects to the cloud by default. Sign in on the new device with the same login method you used originally, and the project library loads.

Use the same method deliberately. CapCut's help center notes that different sign-in methods can create separate accounts even when the email address looks the same. If you signed up with TikTok, use TikTok; if you used Google, use Google.

### QR login from mobile to desktop

The fastest way to link a phone and a computer is CapCut's QR login:

1. Sign in to CapCut on your phone.
2. Open CapCut on desktop, online, or the PC app and choose Sign in.
3. Select QR code login.
4. On the phone, open Me, then Scan, and scan the code.
5. Confirm the login on the phone.

CapCut's help center says projects, drafts, and account data then sync automatically between the two devices.

## If the project is missing: local versus cloud

A project created before you signed in may exist only on the original device. On the PC app, open the projects library and toggle between Cloud and Local views. The Local Projects section is where unsynced drafts live.

Other things to check:

- Confirm you are on the correct account, especially if you have more than one login method.
- Check the Trash; deleted projects can often be restored.
- Make sure the app is updated on both devices.
- For cross-platform cloud use, CapCut's help center says projects must be uploaded to Spaces.

Cloud sync also needs an internet connection. A project that opens on the same device offline is not proof that it reached the cloud.

## Moving a CapCut edit into another editor

There is no native CapCut project interchange format for other editors. CapCut does not advertise a way to export a timeline that Premiere, Resolve, Final Cut, or a browser editor can open with tracks, effects, and keyframes intact.

You have two realistic options:

**Option A: finish in CapCut, export the video.** Export the final MP4 and use the new editor only for future projects. This is the cheapest and least error-prone route.

**Option B: rebuild the timeline somewhere else.** Export the source clips you still have, collect the music and fonts, write down the cuts, and rebuild. For short social videos this is often 20–40 minutes. For a long project, it can be hours.

If you choose Option B, do it in this order:

1. Export every source clip you still have at the highest available quality.
2. Screenshot the timeline and any text or effect settings you want to keep.
3. Download or re-source the music and fonts. Pro assets from CapCut cannot be reused elsewhere.
4. Rebuild in the new editor before deleting the CapCut project.

Keep the CapCut project until the new edit is exported and reviewed. Cloud storage is not a backup you control.

## Sharing a project without sharing your account

CapCut's cloud sync is account-based. If a collaborator needs the project, the practical options are to export the final video, export source clips, or hand over the account credentials, which is rarely a good idea. There is no documented "send project file" step in the sync flow.

## Troubleshooting checklist

If a project will not appear on the second device:

- Sign out and back in with the original method.
- Check Cloud versus Local in the desktop library.
- Confirm the project is in Spaces, not only on the device.
- Check Trash and the correct account.
- Update the app on both devices.
- Test with a small new project to see whether sync itself is working.
